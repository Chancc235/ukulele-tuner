# 产品需求文档：PWA MVP

## 1. 产品目标

让用户在一台 iOS 26 iPhone 上，用最少操作调准标准 High-G 尤克里里的四根弦。产品只解决调音：快、稳、离线、无账号、无广告、无音频上传。

## 2. 平台与安装

- iPhone，iOS 26。
- Safari 添加到主屏幕并选择“打开为 Web App”。
- 竖屏优先，standalone 显示。
- 首次安装后可离线使用。
- 免费 HTTPS 静态托管。

## 3. 四根弦与四个弦钮

| 弦序 | 音名 | 目标频率 | App 按钮 |
| ---: | --- | ---: | --- |
| 第 4 弦 | G4 | 391.995 Hz | G |
| 第 3 弦 | C4 | 261.626 Hz | C |
| 第 2 弦 | E4 | 329.628 Hz | E |
| 第 1 弦 | A4 | 440.000 Hz | A |

界面必须同时提供：

- `自动`：从四个目标中选择最近且可信的弦。
- `G/C/E/A`：手动锁定一个实体弦钮对应的弦，不自动跳弦。

App 显示“音高升高/降低”，不显示统一的“顺时针/逆时针”，因为实际方向取决于琴头和绕线方式。

## 4. 音频入口

### 4.1 实时调音

- 用户主动点击后请求麦克风权限。
- 实时显示目标弦、检测频率、cents 和调节方向。
- 没有可信信号时不保留旧读数。
- 提供明确的“停止”按钮。
- 页面隐藏或进入后台时停止麦克风。

### 4.2 选择录音（本机分析）

- 接受 `.m4a`、`.mp3`、`.wav`。
- 文件最大 25 MB、最长分析 30 秒。
- 首版使用说明要求：录制 2–10 秒，一次只拨一根弦。
- 显示文件名、分析进度和最终稳定结果。
- 解码失败时说明推荐使用语音备忘录默认 `.m4a`。
- 分析结束或用户重新选择后释放 AudioBuffer 引用。
- 文件和 PCM 不发送到网络、不缓存到 Service Worker。

## 5. 页面信息结构

1. 顶部：UkeTune、离线/在线状态、隐私简述。
2. 核心读数：目标音名、cents、当前频率、状态文案、视觉指针。
3. 四弦控制：自动、G、C、E、A。
4. 输入方式：开始/停止实时调音，选择录音。
5. 操作提示：一次拨一根弦、手机距琴约 20–40 cm。
6. 安装/更新提示和版本号。

## 6. 状态定义

| 状态 | 条件 | 表现 |
| --- | --- | --- |
| 就绪 | 未启动输入 | 提示选择实时或录音 |
| 等待 | 音量不足 | 提示拨动一根弦 |
| 分析中 | 正在处理录音 | 显示进度，不显示旧结果 |
| 不确定 | 有声但置信度低/离目标太远 | 提示靠近、减少噪声或手动选弦 |
| 偏低 | cents < -5 | “音高偏低，请升高” |
| 准确 | -5 ≤ cents ≤ +5 | “准了”与明显成功状态 |
| 偏高 | cents > +5 | “音高偏高，请降低” |
| 权限拒绝 | 麦克风被拒 | 给出设置说明和录音入口 |
| 错误 | 浏览器/解码失败 | 可操作的恢复建议，不只显示错误码 |

## 7. MVP 验收标准

### 调音

- 四个目标频率和 `spec/standard-high-g.json` 一致。
- 合成音稳定误差不超过 ±3 cents。
- “准了”阈值为 ±5 cents。
- 强二次泛音不能持续造成高八度误判。
- 第一条有效反馈目标 ≤300 ms，稳定反馈目标 ≤500 ms。
- 输入消失后 500–800 ms 清空旧结果。

### 四弦交互

- 自动模式可识别 G/C/E/A。
- 手动选择后不会切到其他弦。
- 四个按钮在单手持琴时仍易点击。
- 不使用可能错误的顺/逆时针提示。

### 实时麦克风

- 允许、拒绝、停止、重试和页面后台切换均不崩溃。
- 所有 MediaStream tracks 在停止后确实结束。
- 麦克风失败时始终能进入录音文件模式。

### 录音文件

- iOS 语音备忘录默认 `.m4a` 能被选择和分析。
- WAV/MP3 测试夹具能分析。
- 不支持、过大、过长或无有效音高的文件给出清晰提示。
- DevTools 网络记录中没有录音上传请求。

### PWA

- manifest、Service Worker 和图标有效。
- Safari 可添加到主屏幕并以 Web App 打开。
- 首次缓存完成后，飞行模式重新打开仍能进入应用并分析本地录音。
- 更新时不出现永久旧缓存。

## 8. 非目标

- Low-G 和其他定弦。
- 吉他、节拍器、课程、录音保存、账号、云同步。
- 自动判断实体弦钮的顺/逆时针旋转方向。
- 后台监听。
- 服务端音频识别或 AI 模型调用。
- App Store 发布。

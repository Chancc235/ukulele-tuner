# PWA 开发计划与质量节奏

## M0：可行性和技术决定（已完成）

- 验证 iOS 26 主屏幕 Web App、麦克风、Web Audio、录音导出和免费托管可行性。
- 通过 ADR-0002，原生 Swift 路线进入归档。
- 冻结一台 iPhone、High-G 四弦、零后端范围。

## M1：工程与文档收敛（本地完成）

- 建立无第三方运行时依赖的静态 PWA 目录。
- 建立 npm 命令、Node 测试、静态校验和本地服务器。
- 重写需求、架构、部署、测试和发布文档。
- 建立开发日志、测试报告和 code review 记录目录。

退出条件：项目结构明确，所有活跃文档不再把 Xcode/TestFlight 当主方案。

## M2：调音核心（本地完成）

- High-G 配置、cents、自动/手动弦匹配。
- YIN detector、RMS/置信度门限。
- 稳定器、状态滞回、信号超时。
- 合成音：四目标、±cents、强二次泛音、静音、噪声。

退出条件：自动测试全部通过，合成音误差 ≤±3 cents。

质量门：`npm test` 和 `npm run check` 已通过，结果包含在本地 MVP 报告与 CR-001。

## M3：PWA 应用壳（本地完成）

- 单页竖屏 UI、自动 + G/C/E/A 四弦按钮。
- manifest、图标、safe-area、安装提示。
- Service Worker 离线缓存和版本更新提示。
- 在线/离线、权限和错误状态。

退出条件：manifest/Service Worker 结构校验和本地 HTTP 冒烟已通过；桌面真实浏览器交互仍列入部署前测试。

质量门：静态检查和代码级键盘/触控/ARIA review 已包含在 CR-001；真实浏览器部分留给 CR-002。

## M4：实时麦克风（实现完成，等待 HTTPS/iPhone 验收）

- 用户手势启动 AudioContext 和 getUserMedia。
- 约 20 Hz 的 PCM 分析循环。
- start/stop、后台自动停止、错误恢复。
- 实时结果接入共享稳定器和 UI。

退出条件：HTTPS 环境下 iPhone 能完成四弦实时调音；权限拒绝不阻塞其他入口。

质量门：桌面浏览器功能测试 + iPhone 手测报告；审查资源清理、并发和隐私。

## M5：本地录音识别（实现完成，等待真实 M4A/MP3/iPhone 验收）

- 文件格式/大小/时长校验。
- decodeAudioData、分窗检测、进度和 yield。
- 稳定聚合结果与可操作错误。
- 明确验证零网络上传。

退出条件：M4A/WAV/MP3 测试文件识别；实时麦克风不可用时仍能完成调音判断。

质量门：全部本地测试、资源释放和静态零上传检查已包含在 CR-001；真实文件和 Safari 网络检查留给 CR-002。

## M6：免费部署（下一步，预计 0.5 天）

- 已准备 GitHub Pages workflow 和 HTTPS 静态目录。
- 用户创建/选择 GitHub 仓库，并在自己的浏览器中完成账号登录。
- 在仓库 Settings -> Pages 选择 GitHub Actions。
- 发布 URL、版本、缓存号和回滚说明。

退出条件：获得 HTTPS 发布地址，Wi-Fi 和蜂窝网络均能打开。

## M7：一台 iPhone 验收（预计 1 天）

- Safari 首次访问、添加到主屏幕、standalone 启动。
- 麦克风允许/拒绝/撤回/重试。
- 语音备忘录 -> 存储到文件 -> 选择录音。
- 飞行模式离线启动与使用。
- 独立调音器对照四弦准确度。

退出条件：所有 P0 测试通过。

## 持续记录规则

### 开发日志

- 每个实现阶段结束更新 `docs/DEVLOG.md`。
- 记录事实、决定、完成内容、已知问题和下一步，不写模糊“优化了一些东西”。

### 功能测试

- 每次修改 DSP、缓存、麦克风或文件分析后运行完整自动测试。
- 每个里程碑写入 `docs/test-reports/YYYY-MM-DD-<scope>.md`。
- 真机才能验证的项目明确标记 Pending，不用桌面结果冒充 iPhone 通过。

### Code review

- M2、M3、M5 和发布前各做一次正式 review。
- 记录到 `docs/reviews/CR-xxx-<scope>.md`。
- 必查：正确性、资源释放、错误恢复、隐私、离线更新、可访问性和测试缺口。
- Review 发现的 P0/P1 必须修复并复测；P2 可进入 backlog，但必须写明理由。

## 用户协作点

- 部署前提供/授权 GitHub 账号，不发送密码或验证码。
- 真机阶段用自己的尤克里里拨弦，并准备一个独立参考调音器。
- 如果希望四个弦钮按钮与实体琴头左右位置完全一致，提供一张琴头正面照片；否则首版按 G-C-E-A 弦序展示。
